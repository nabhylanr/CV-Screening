# Kasus pilot (bukan data uji)

3 pasangan CV–JD dari split **train** dataset `cnamuangtoun/resume-job-description-fit` (baris 1510, 4472, 4719), tidak ada yang sama dengan 10 kasus uji.
Dipakai hanya untuk mengecek prompt **sebelum** uji coba: format JSON, kelengkapan field, kutipan bukti ada di CV, panjang jawaban, dan pemakaian token.
Label sengaja tidak disimpan supaya prompt tidak disetel berdasarkan akurasi.
